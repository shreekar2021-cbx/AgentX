# Data sources and provenance

| Data | Source and purpose | Status and timestamp | Failure behavior / attribution |
| --- | --- | --- | --- |
| Crop image and symptoms | Farmer submission; optional [Mistral vision](https://docs.mistral.ai/studio/conversations/vision) through backend `MistralProvider` | `AI LIVE` or `AI CACHED`; `analyzed_at`; `image_assessed` | Missing key, 429, timeout, malformed output, or failure gives `LOCAL KNOWLEDGE`/`LIMITED MODE`, explicitly text only. No fake image assessment. |
| Crop issue reference | 18 crop / 54 issue curated local catalog, informed by [TNAU IPM](https://agritech.tnau.ac.in/crop_protection/crop_prot_ipm.html) and [ICAR advisories](https://www.icar.gov.in/) | `CURATED STATIC KNOWLEDGE`, catalog version | Non-diagnostic text matching; low confidence cannot trigger an outbreak signal. |
| Weather | [Open-Meteo Forecast API](https://open-meteo.com/en/docs), current/hourly/daily context | `LIVE`, `CACHED`, or `LOCAL KNOWLEDGE`; observed/fetch times and `stale` | Stale cache is marked; otherwise no current value is invented. Follow [Open-Meteo terms](https://open-meteo.com/en/terms) for commercial use and attribution. |
| Nearby reports | Owner-scoped local reports and fixed-seed synthetic network; Haversine clustering | Individual report dates and `is_synthetic`; coarse public centers | Real and synthetic evidence are separated; no network access returns a labelled unavailable state. |
| Mandi prices | Optional [Government of India OGD daily mandi resource](https://data.gov.in/resource/current-daily-price-various-commodities-various-markets-mandi) | `LIVE`/`CACHED`, quote date, fetched time, provenance | Stale cache labelled. Without usable provider/cache, 4,800 fixed-seed **synthetic** observations through 2026-08-31 return `FALLBACK` and `is_synthetic=true`; they are not official current prices. |
| Market direction | Optional backend Mistral classification of dated history | `AI LIVE`/`AI CACHED`, confidence and horizon | A deterministic historical direction is labelled `DETERMINISTIC`; neither path guarantees a future price. |
| Farm and soil | Farmer-entered profile, portfolio, and lab categories; synthetic sample in demo | `updated_at`; seeded records carry `is_synthetic` | Missing soil values remain unknown. No invented lab thresholds or exact fertilizer doses. |
| Market net return | Farmer-entered quantity and costs, calculated with decimal arithmetic | Deterministic estimate, no external timestamp | No model computes totals; actual proceeds may differ. |
| Notifications | Persistent in-app local store; sample notices have `is_synthetic` | `created_at` and `read_at` | Persistence failure is recorded in provider health and does not fail analysis. No push/SMS/email delivery is claimed. |
| Map tiles | [OpenStreetMap](https://www.openstreetmap.org/copyright) data via [CARTO basemap](https://carto.com/attributions/) | Online third-party base tiles | Cluster data remains in the app; map tiles need connectivity. Attribution stays on the map. |
| Voice transcription | Optional browser Web Speech recognition | Browser-dependent; no app-side recording retained | Text input works when voice is absent. [MDN](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition) notes browser support and possible server-based processing. |

The synthetic network uses seed `260926` and stable UUIDs. Its startup timestamps are refreshed to keep example clusters demonstrable; this is a demo clock, not a claim of current farmer observations. `scripts/generate_demo_data.py` and `scripts/generate_market_data.py` reproduce the source datasets. API fields and UI badges distinguish synthetic, static, cached, and live results.
